# Audio Assets

Place audio files here:
- `bg_music.mp3` - Background music (looping)
- `dice_roll.mp3` - Dice rolling sound
- `purchase.mp3` - Property purchase sound
- `correct.mp3` - Correct answer sound
- `wrong.mp3` - Wrong answer sound
- `win.mp3` - Victory sound
- `lose.mp3` - Game over sound

Audio is currently synthesized using Web Audio API / Web Speech API.
